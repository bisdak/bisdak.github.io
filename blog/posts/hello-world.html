Hello, world

This is the first post, and it exists mostly so you have something to copy when you write the second one. Delete it whenever you like — the blog index reads from blog/posts.json, so removing this file and its entry is all it takes.

What goes here

Anything you'd want a stranger to read: a bug that took a day to find, a tool you built and why, notes from a book. Writing about your own work is the cheapest way to make a portfolio feel alive rather than static.

How to add a post

  1. Copy this file to a new name inside blog/posts/.
  2. Edit the title, date, and body.
  3. Add an entry to blog/posts.json.

That's it. No build step, no deploy command beyond committing.

Write the thing you wished you'd found when you got stuck.
